## 프로젝트 개요

본 프로젝트는 네트워크 기초 개념 학습 및 실습을 위한 과제입니다. 주어진 10개의 레벨에서 네트워크 문제들을 해결하여 네트워크를 정상적으로 작동시키는 것을 목표로 합니다.

## 수행 내용

-   제공된 `index.html` 파일을 웹 브라우저에서 실행하여 훈련 인터페이스를 사용했습니다.
-   각 레벨별로 제시된 네트워크 문제 상황을 분석하고, 필요한 설정을 변경하여 네트워크를 정상화했습니다.
-   각 레벨을 완료할 때마다 "Get my config" 버튼을 사용하여 설정을 파일로 내보냈습니다.

## 결과물 설명

본 레포지토리는 NetPractice 과제의 결과물로, 각 레벨별로 내보낸 설정 파일들을 포함하고 있습니다. 각 파일은 해당 레벨의 네트워크 설정을 담고 있으며, 문제 해결을 위해 제가 수행한 설정을 확인할 수 있습니다.

## 주의사항

-   본 결과물은 훈련 인터페이스에서 제공하는 가상 네트워크 환경에서의 설정입니다.
